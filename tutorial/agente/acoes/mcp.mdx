## **🎯 Objetivo do Tutorial**

O MCP permite que seu agente acesse ferramentas e bancos de dados externos (como Supabase ou n8n) de forma nativa e estruturada.

## **📝 Configuração**

1. **URL do Servidor:** Insira o endereço do seu servidor MCP.
2. **Autenticação:** Adicione o **Bearer Token** se o seu servidor for privado (recomendado para produção).
3. **Validação:** Clique em **Próximo** para ver o resumo das ferramentas que o servidor disponibiliza.
4. **Finalização:** Uma vez criado, o agente terá acesso às funções do servidor para realizar consultas ou automações complexas.

---

## **💡 Dica**
MCPs são ideais para quando você precisa que a IA faça buscas em bancos de dados SQL ou execute scripts Python complexos externamente.
