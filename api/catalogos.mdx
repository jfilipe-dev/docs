<Visibility for="agents">
**Quando ler esta página:** quando for descobrir os ids e slugs que as outras rotas pedem: `GET /kanban` (colunas do funil), `GET /tags`, `GET /properties` (com `property_type` TEXT/NUMBER/ENUM/FLOAT_ENUM e `display_format`) e `GET /properties/{slug}/values` (valores aceitos de uma propriedade em lista, com `numeric_value` em FLOAT_ENUM), com respostas, erros e exemplos.
</Visibility>

As rotas de lead pedem **ids** (de coluna e de tag) e **slugs** (de propriedade), nunca
nomes. Os catálogos devolvem esses identificadores para o projeto da chave.

| Rota | Devolve | Usado em |
|---|---|---|
| `GET /kanban` | Colunas do funil, com id | `PATCH /leads/{numero}/kanban` (`column_id`) |
| `GET /tags` | Tags, com id | `POST`/`DELETE /leads/{numero}/tag` (`tag_id`) |
| `GET /properties` | Propriedades, com slug | `PATCH /leads/{numero}/properties` (`property`) |
| `GET /properties/{slug}/values` | Valores aceitos de uma propriedade em lista | `value` da mesma rota |

Os catálogos são só leitura. Criar ou mudar colunas, tags e propriedades é configuração:
pelo painel, pelo MCP ou pela [API de template](/api/template).

<Tip>
Os ids não mudam quando alguém renomeia uma coluna ou tag. Guarde os ids no seu sistema e
consulte o catálogo de vez em quando para pegar itens novos.
</Tip>

## `GET /kanban`

```bash
curl "https://api.zatten.com/api/v1/kanban" \
  -H "x-api-key: $ZATTEN_API_KEY"
```

**200**: uma lista, na ordem do funil (a primeira é a coluna de entrada).

```json
[
  { "id": "c0l00000-0000-4000-8000-000000000003", "name": "Novo lead", "color": "#3B82F6" },
  { "id": "c0l00000-0000-4000-8000-000000000009", "name": "Orçamento enviado", "description": "Lead recebeu o valor", "color": "#F59E0B" }
]
```

| Campo | O que é |
|---|---|
| `id` | Id da coluna. |
| `name` | Nome. |
| `description` | Descrição. Some quando vazia. |
| `color` | Cor. Some quando vazia. |

Também serve para conferir de qual projeto é uma chave: compare as colunas com as do
projeto que você espera.

## `GET /tags`

```bash
curl "https://api.zatten.com/api/v1/tags" \
  -H "x-api-key: $ZATTEN_API_KEY"
```

**200**: uma lista com os mesmos campos das colunas.

```json
[
  { "id": "b2c1d0e9-0000-4000-8000-000000000001", "name": "Clareamento", "color": "#10B981" },
  { "id": "b2c1d0e9-0000-4000-8000-000000000002", "name": "VIP", "description": "Paciente recorrente", "color": "#8B5CF6" }
]
```

## `GET /properties`

```bash
curl "https://api.zatten.com/api/v1/properties" \
  -H "x-api-key: $ZATTEN_API_KEY"
```

**200**

```json
[
  { "id": "a7b8c9d0-0000-4000-8000-000000000010", "name": "Cidade", "slug": "cidade", "is_enum": false, "property_type": "TEXT", "display_format": "NONE" },
  { "id": "a7b8c9d0-0000-4000-8000-000000000011", "name": "Convênio", "slug": "convenio", "description": "Plano de saúde do paciente", "is_enum": true, "property_type": "ENUM", "display_format": "NONE" },
  { "id": "a7b8c9d0-0000-4000-8000-000000000012", "name": "Valor do orçamento", "slug": "valor_orcamento", "is_enum": false, "property_type": "NUMBER", "display_format": "CURRENCY_BRL" },
  { "id": "a7b8c9d0-0000-4000-8000-000000000013", "name": "Plano", "slug": "plano", "is_enum": true, "property_type": "FLOAT_ENUM", "display_format": "CURRENCY_BRL" }
]
```

| Campo | O que é |
|---|---|
| `slug` | O identificador usado na API, nos templates (`{{slug}}`) e nas tools do agente. |
| `name` | Nome no painel. |
| `property_type` | O tipo, que decide o valor aceito ao gravar (ver abaixo). |
| `display_format` | `NONE` ou `CURRENCY_BRL` (o painel mostra o número como moeda, R$). Moeda só existe em `NUMBER` e `FLOAT_ENUM`. Não muda o que a API aceita: o valor vai sem `R$`. |
| `is_enum` | Campo antigo. `true` nas propriedades com valores pré-definidos (`ENUM`, `FLOAT_ENUM`). Prefira `property_type`. |
| `description` | Descrição. Some quando vazia. |

| `property_type` | O que é | Valor ao gravar no lead |
|---|---|---|
| `TEXT` | Texto livre | Qualquer texto |
| `NUMBER` | Número | Dígitos com ponto decimal: `"1999.90"`, `"-3"`. Sem vírgula nem separador de milhar. |
| `ENUM` | Valores pré-definidos | Um dos `value` de `GET /properties/{slug}/values` |
| `FLOAT_ENUM` | Valores pré-definidos, cada um com um número (`numeric_value`), que as métricas do funil somam | Um dos `value` (o slug da opção, como `plano_anual`), nunca o número |

## `GET /properties/{slug}/values`

Lista os valores aceitos de uma propriedade com valores pré-definidos.

```bash
curl "https://api.zatten.com/api/v1/properties/convenio/values" \
  -H "x-api-key: $ZATTEN_API_KEY"
```

**200**

```json
{
  "slug": "convenio",
  "name": "Convênio",
  "is_enum": true,
  "property_type": "ENUM",
  "display_format": "NONE",
  "values": [
    { "id": "f1e2d3c4-0000-4000-8000-000000000020", "value": "Unimed", "numeric_value": null },
    { "id": "f1e2d3c4-0000-4000-8000-000000000021", "value": "Particular", "description": "Sem convênio", "numeric_value": null }
  ]
}
```

Numa propriedade `FLOAT_ENUM`, cada opção traz o número dela:

```json
{
  "slug": "plano",
  "name": "Plano",
  "is_enum": true,
  "property_type": "FLOAT_ENUM",
  "display_format": "CURRENCY_BRL",
  "values": [
    { "id": "f1e2d3c4-0000-4000-8000-000000000030", "value": "plano_mensal", "description": "Plano mensal", "numeric_value": 199.9 },
    { "id": "f1e2d3c4-0000-4000-8000-000000000031", "value": "plano_anual", "description": "Plano anual", "numeric_value": 1999 }
  ]
}
```

| Campo da opção | O que é |
|---|---|
| `value` | O que você manda ao gravar. Em `FLOAT_ENUM` é um slug (`a-z`, `0-9`, `_`, `-`). |
| `description` | O texto que o painel mostra. Some quando vazio. |
| `numeric_value` | O número da opção em `FLOAT_ENUM`. `null` em `ENUM`. |

Mande o `value` exatamente como vem aqui (maiúsculas e acentos contam). Em
`FLOAT_ENUM`, mande o `value`, não o `numeric_value` nem a `description`.

| Código | `error` | Causa |
|---|---|---|
| 404 | `Property not found` | Slug inexistente no projeto. |
| 400 | `Property "…" is a text property and accepts any value` | A propriedade é de texto livre: não tem lista. |

## Erros comuns aos catálogos

| Código | `error` | Causa |
|---|---|---|
| 401 | `Invalid API key` | Chave errada. |
| 404 | `No kanban columns found` / `No tags found` | Falha momentânea ao ler o catálogo. Tente de novo. |

Projeto sem tags (ou sem propriedades) devolve lista vazia (`[]`), não 404.

## Pelo MCP

O MCP (`get_template`) traz colunas, tags e propriedades com **nome e slug**, para
configurar. A API traz os **ids** que as rotas de lead pedem. Para operar leads pela API,
use os catálogos daqui. Ver [Referência do template](/trabalhar-com-ia/referencia-do-template).

## Armadilhas

- **Nome não serve como identificador.** Coluna e tag vão pelo id; propriedade, pelo
  slug.
- **Slug não é o nome.** "Convênio" tem slug `convenio`. Confira em `GET /properties`.
- **Em `FLOAT_ENUM`, grave o `value`, não o número.** Mandar `1999` numa propriedade
  `FLOAT_ENUM` dá 400; mande `plano_anual`.
- **Moeda é só exibição.** `display_format: "CURRENCY_BRL"` não muda o valor aceito:
  grave `"1999.90"`, nunca `"R$ 1.999,90"`.
- **Valor de lista é exato.** `unimed` não é `Unimed`.
- **Ids são por projeto.** A tag "VIP" de um cliente tem outro id no outro cliente. Não
  reaproveite ids entre projetos.
