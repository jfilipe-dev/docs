**Quando ler esta página:** quando a agência quiser crescer: achar o que vender a mais para os clientes que já tem (upsell) e escolher nichos vizinhos para prospectar, a partir dos projetos e do AGENCIA.md.
</Visibility>

A venda mais fácil é para quem já é cliente. A segunda mais fácil é para um
negócio parecido com os que a agência já atende.

## Na carteira: o que vender a mais

O [diagnóstico de um projeto](/trabalhar-com-ia/diagnostico) mostra o que falta em
cada cliente. Cada lacuna é uma oportunidade:

| O projeto não tem | A oportunidade | Playbook |
|---|---|---|
| Follow-up ou reengajamento | Recuperar leads que pararam de responder | [Follow-up e reengajamento](/playbooks/follow-up-e-reengajamento) |
| Conversões no Meta Ads (e o cliente anuncia) | Medir e otimizar o anúncio pelo que vende | [Anúncios Click-to-WhatsApp](/playbooks/anuncios-ctwa) |
| Agenda integrada (e o negócio tem hora marcada) | O agente marca sozinho | [Agendamento](/playbooks/agendamento) |
| Qualificação antes do comercial | Vendedor só fala com quem está pronto | [Qualificação](/playbooks/qualificacao) |
| Campanhas | Reativar a base de contatos | [Campanhas](/playbooks/campanhas) |
| Relatório mensal | Mostrar resultado e segurar o cliente | [Entregar ao cliente](/playbooks/entregar-ao-cliente) |

O assistente lê os projetos (`get_template`, `get_metrics`) e devolve uma lista
priorizada, cliente por cliente, com o porquê. A agência escolhe o que oferecer.

## Fora da carteira: nichos vizinhos

Um nicho vizinho usa quase o mesmo projeto. A agência reaproveita o que já sabe
fazer e o que já tem como prova.

| A agência atende | Nichos vizinhos |
|---|---|
| Clínicas | Odontologia, estética, fisioterapia, psicologia, pet |
| Imobiliárias | Construtoras, administradoras de condomínio, loteamentos |
| Academias | Estúdios de pilates, crossfit, escolas de dança |
| Cursos | Mentorias, escolas de idiomas, preparatórios |
| Advocacia | Contabilidade, despachantes, consultorias |

Os playbooks prontos estão em [Nichos](/playbooks/como-usar).

## Como o assistente ajuda

- Cruza a carteira (organizações e projetos) com o `AGENCIA.md` para sugerir onde
  crescer.
- No fim de uma sessão, quando faz sentido, faz **uma** sugestão concreta ("três
  clientes de clínica não têm lembrete de consulta: quer que eu monte uma
  proposta de upsell?").
