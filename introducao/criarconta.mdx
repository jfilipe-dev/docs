Este guia mostra a **jornada inicial na Zatten**, do cadastro até deixar o
primeiro agente pronto para configuração.

## Passo a passo

<Steps>
  <Step title="Escolha o método de cadastro">
    Você pode criar a conta de duas formas:
    - **Cadastro manual:** preencha os dados solicitados.
    - **Login com Google:** use sua conta Google para agilizar.
  </Step>
  <Step title="Identifique o projeto">
    Dê um nome ao projeto. Esse nome aparece no painel e ajuda a separar
    operações diferentes.
    <Tip>
      Se o agente é para qualificação de leads, um bom nome é algo como
      `Maia SDR` ou `Atendimento Vendas`.
    </Tip>
  </Step>
  <Step title="Defina o objetivo do agente">
    Descreva, em uma frase, o que o agente vai fazer. Ainda não precisa ser o
    prompt final — é apenas um norte.
    > Exemplo: *"Atuar como SDR para qualificar leads via WhatsApp."*
  </Step>
  <Step title="Configure a precificação">
    Informe o **valor mensal** planejado para esse projeto (ex: R$ 5.000,00).
    Esse valor é usado apenas no seu painel de controle administrativo —
    não é cobrado pela Zatten.
  </Step>
  <Step title="Pronto: agente criado">
    Ao concluir, seu primeiro agente é criado e a plataforma fica disponível
    para as configurações avançadas.
  </Step>
</Steps>

## Dicas importantes

<CardGroup cols={2}>
  <Card title="Objetivo é editável" icon="pen-to-square">
    O objetivo definido no cadastro pode ser ajustado depois nas configurações
    do agente.
  </Card>
  <Card title="Precificação é só visual" icon="chart-line">
    O valor informado serve apenas para controle administrativo do seu white
    label. Não influencia cobrança nem permissões.
  </Card>
</CardGroup>
